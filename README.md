# HAMi Learning Resources

> Educational repository for learning HAMi: GPU Virtualization & Sharing on Kubernetes

Part of **CNCF Project Focus** series, exploring cloud-native technologies in depth.

## About This Repository

This repository contains learning materials and educational examples for **HAMi** (Heterogeneous AI Computing Virtualization Middleware), the CNCF project for GPU virtualization and sharing on Kubernetes.

**Educational focus.** Real code and examples.
